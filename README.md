# 読書ログ

読書した時間・書名・感想を、できるだけ少ない操作で記録するiPhone向けアプリ。
ホーム画面に追加すると、普通のアプリのように全画面で起動します（PWA）。電波がなくても開けます。

## iPhoneでの使い始め方

**公開URL：https://tabashow.github.io/reading-log/**

1. iPhoneの**Safari**で上のURLを開く
2. 共有ボタン（□に↑）→ **「ホーム画面に追加」**
3. **ホーム画面のアイコンから**アプリを開いて使う

**Safariのタブとホーム画面のアプリでは、データの保存場所が別々です。** Safariで記録した内容はホーム画面のアプリに出てきません。Safariで開いている間は、画面上部に案内が表示されます。

## Macからの引き継ぎ

1. **Mac**でアプリ（`index.html`）を開き、統計タブ →「バックアップ」でJSONを保存する
2. そのJSONを**AirDrop**かiCloud DriveでiPhoneに送る
3. iPhoneの**ホーム画面のアプリ**を開く → 統計タブ →「バックアップから復元」→ JSONを選ぶ
   （本が1冊もない状態なら、記録タブの「バックアップから復元する」からも選べます）

本・記録・感想・★評価・しおりがすべてそのまま移ります。復元すると、iPhone側にあったデータは置き換わります。

## 記録の流れ（最短2タップ）

1. 「最近の本」のチップをタップ → **その瞬間に計測が始まる**
2. 読み終えたら「読み終わった（記録する）」をタップ
3. 出てくる保存画面は、**そのまま「保存する」を押すだけで完了**

感想・ページ・評価はすべて任意。あとから記録一覧の「＋ 感想を書く」で追記できます。
一時停止／再開もでき、途中でアプリを閉じても計測状態は残ります。

## 機能

| タブ | できること |
|---|---|
| 記録 | タイマー計測（一時停止・再開・破棄）、時間の手入力（読書中の本のみ表示）、最近の記録一覧と感想の追記 |
| ライブラリ | 本ごとの合計時間・回数・感想の一覧、書名/著者/感想の全文検索。本をタップすると**書名・著者・しおりページ・★評価・読了フラグを編集**できる |
| 統計 | 直近7日/30日/累計、読了冊数、連続記録日数、直近14日の棒グラフ、約4か月の読書カレンダー、よく読んだ本 |

そのほか：しおり代わりのページ記録、CSV書き出し（Excel対応・BOM付き）、JSONバックアップ／復元、ダークモード対応、オフライン起動。

## データについて

- 記録は**iPhoneの中（localStorage）だけ**に保存されます。サーバーには何も送信しません。公開されるのはアプリの画面（HTML）だけで、記録は他の人からは見えません。
- **ホーム画面からアプリを削除すると記録も消えます。** 機種変更にも備えて、ときどき統計タブの「バックアップ」→「ファイルに保存」でiCloud Driveなどに保存してください。
- CSV書き出しの列：日付, 開始時刻, 書名, 著者, 分, ページ, 評価, 読了, 感想

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。HTML/CSS/JavaScript が1ファイルに収まっています。依存ライブラリなし |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・全画面表示の設定 |
| `sw.js` | Service Worker。画面一式をキャッシュして、圏外でも起動できるようにする |
| `icons/` | アプリアイコン（180 / 192 / 512px） |

### 更新するとき

- `index.html` の変更は、iPhoneがネットにつながった状態でアプリを開けば自動で反映されます。
- アイコンや `manifest.webmanifest` を差し替えたときは、`sw.js` の `VERSION` を上げてください（古いキャッシュが残るのを防ぐため）。
